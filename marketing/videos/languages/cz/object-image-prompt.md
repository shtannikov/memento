# Czech vocabulary image

Create one photorealistic image of the specified concept for a vertical vocabulary quiz.

- Prefer one complete object when the concept has a concrete, unambiguous visual representation.
- For an action, process, interaction, or otherwise non-object concept, create a compact realistic scene based on a user-approved reference image.
- Make the intended answer immediately recognizable and minimize plausible alternative answers.
- Use realistic shape, proportions, materials, textures, studio lighting, and a soft natural shadow.
- Isolate an object on a genuinely transparent background with clean edges. For a compact scene, use the user-approved background treatment; a seamless pure white background is valid when it will blend into the white video card.
- Fill roughly 65–75% of the usable square canvas without cropping any important part.
- Use the most familiar front or gentle three-quarter view.
- Keep the visual style consistent with the other images in the episode.
- Include no logos, watermark, decorative copy, or unrelated props.
- Text is allowed only when the item prompt gives exact English wording needed to disambiguate the answer. Render that wording verbatim and include no other readable text.
- Do not turn the subject into a toy, mascot, emoji, icon, sticker, flat vector, cartoon, or stylized 3D character.

Create only the requested photorealistic image. Do not offer an alternative illustration style.
